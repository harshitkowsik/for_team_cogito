# Music Player - Team Cogito (Code Cauldron Hackathon)

**Music Player** is a web-based audio player application developed by Team Cogito for the Code Cauldron Hackathon. The project demonstrates the creation of a minimalist, user-friendly music player using core web technologies. It allows users to play, pause, and navigate through a curated playlist, providing a seamless listening experience right in the browser.

## Project Overview

This music player was built as a hackathon submission by Team Cogito. It focuses on:

- Simple and intuitive user interface
- Core music playback controls (play, pause, next, previous)
- Playlist management for multiple tracks
- Responsive design for desktop and mobile

---

## Features

- **Play/Pause Controls:**  
  Easily start or stop audio playback.

- **Next/Previous Track:**  
  Navigate through the playlist with dedicated controls.

- **Track Information Display:**  
  See the current song’s title and artist.

- **Progress Bar:**  
  Visualize playback progress and seek within the track.

- **Responsive UI:**  
  Enjoy a consistent experience across devices.

---

## Technology Stack

- **HTML5** — Semantic structure and audio element
- **CSS3** — Styling and responsive layout
- **JavaScript (ES6+)** — Playback logic, UI updates, and playlist management

## Getting Started

1. **Clone the repository:**
    ```
    git clone https://github.com/harshitkowsik/for_team_cogito.git
    cd for_team_cogito
    ```

2. **Add Your Music (Optional):**
    - Place your audio files (e.g., `.mp3`, `.wav`) in the `assets/` folder.
    - Update the playlist in `script.js` if you want to use your own tracks.

3. **Open the Application:**
    - Open `index.html` in your preferred web browser.

---

## How It Works

- **Audio Playback:**  
  The HTML `<audio>` element is controlled via JavaScript to play, pause, and switch tracks.

- **Playlist Management:**  
  The playlist is defined in the JavaScript file and can be easily customized.

- **User Controls:**  
  UI buttons trigger playback functions and update the display in real time.

- **Progress Bar:**  
  Shows current playback position and allows seeking.

---

## Customization

- **Add/Remove Tracks:**  
  Edit the playlist array in `script.js` to include your own songs and cover images.

- **Styling:**  
  Modify `style.css` to change the color scheme, fonts, or layout.

- **UI Enhancements:**  
  Add features like shuffle, repeat, or volume control by extending `script.js`.
